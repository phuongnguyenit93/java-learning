# Security – JSON Web Token (JWT)

JSON Web Token (JWT) là một định dạng token gọn nhẹ dùng để truyền các thông tin xác nhận (*claims*) giữa những bên tham gia hệ thống. JWT không tự nó là giao thức đăng nhập hay phân quyền, và nội dung mã hóa Base64url không đồng nghĩa với việc được giữ bí mật. Việc sử dụng JWT an toàn đòi hỏi hiểu rõ mục đích của token, mô hình tin cậy giữa bên phát hành và bên nhận, cũng như giới hạn của token tự chứa khi cần hết hạn hoặc thu hồi quyền truy cập.

Module dành cho người đã biết khái niệm xác thực, phân quyền, HTTP và mật mã ứng dụng ở mức cơ bản; nội dung độc lập với ngôn ngữ lập trình hoặc framework cụ thể. Bạn sẽ phân biệt JWT với OAuth 2.0, OpenID Connect và cơ chế phiên, đọc cấu trúc header, claims, cách biểu diễn compact và vai trò của các claims chuẩn. Tiếp theo, bạn tìm hiểu sự khác biệt giữa **JWS** (bảo vệ tính toàn vẹn, xác thực nguồn gốc bằng chữ ký hoặc MAC) và **JWE** (mã hóa nội dung), so sánh HMAC với chữ ký bất đối xứng, rồi thực hành tư duy xác minh token bằng thuật toán được cho phép và nguồn khóa đáng tin cậy.

Ở phần ứng dụng, bạn sẽ kiểm tra bên phát hành, đối tượng nhận, thời hạn và mục đích sử dụng; hiểu cách chọn khóa thông qua JWKS, `kid`, bộ nhớ đệm và xoay khóa. Lộ trình cũng làm rõ sự khác nhau giữa access token, ID token và refresh token, cách lưu trữ và truyền token qua TLS, các rủi ro như nhầm loại token, phát lại, lộ dữ liệu trong claims hoặc nhật ký. Cuối cùng, bạn sẽ kiểm thử token bị sửa, sai khóa, hết hạn và lỗi lấy khóa để xây dựng quy trình chấp nhận hoặc từ chối token có thể kiểm chứng, không phụ thuộc nền tảng triển khai.
