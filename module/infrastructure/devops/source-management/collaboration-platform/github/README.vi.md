# Tổng quan: Cộng tác mã nguồn với GitHub

GitHub là nền tảng lưu trữ repository dựa trên Git, giúp nhóm đưa đề xuất thay đổi vào một nơi có thể thảo luận, đánh giá và kiểm soát quyền tiếp nhận. Git quản lý lịch sử và thao tác phiên bản; GitHub bổ sung repository hosting, pull request, review, phân quyền và quy tắc bảo vệ. Nhờ vậy, việc chia sẻ mã nguồn không tự động đồng nghĩa với việc thay đổi đã được chấp thuận.

**Kiến thức nền:** Nên hiểu trước repository, commit, branch và thao tác trao đổi lịch sử ở mức cơ bản của Git. Module này không dạy lại các lệnh Git.

**Lộ trình học:** Bắt đầu với repository, tài khoản cá nhân/organization, người tham gia và pull request. Tiếp theo tìm hiểu quyền sở hữu, hiển thị của repository, cách đóng góp qua repository chung hoặc fork, vòng đời và đánh giá pull request. Sau đó học cách tổ chức thành viên/team, vai trò truy cập, branch protection và rulesets. Kết nối Issues với Releases trước khi thực hành phân tích một thay đổi từ đề xuất đến hợp nhất.

**Kết quả mong đợi:** Có thể xác định đúng đối tượng và phạm vi trên GitHub, chọn luồng đóng góp phù hợp, hiểu bằng chứng đánh giá, nhận diện nguyên nhân merge bị chặn và biết nơi cần điều chỉnh trên nền tảng.

**Ranh giới:** Chiến lược nhánh của nhóm thuộc module Branching Strategy; Git mechanics thuộc module Git. Tự động hóa GitHub Actions, CI/CD, quản lý phiên bản và triển khai nằm ngoài module này. Issues và Releases được học như giao diện cộng tác, không thay thế toàn bộ quản lý dự án hay quy trình phát hành.
