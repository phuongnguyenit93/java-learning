# Git: quản lý lịch sử thay đổi mã nguồn

Git là hệ thống kiểm soát phiên bản phân tán. Module này tập trung vào **cơ chế Git**: trạng thái tệp, vùng staging, commit, tham chiếu, nhánh và cách lịch sử được trao đổi hoặc khôi phục. Mục tiêu là giúp người học tự giải thích và kiểm chứng điều Git đang lưu giữ trước khi phối hợp trong một nhóm.

**Kiến thức đầu vào:** biết làm việc với tệp, thư mục, terminal và mã nguồn cơ bản. Không cần học trước giao diện GitHub, GitLab hay quy trình phát hành.

**Lộ trình học:** bắt đầu với repository và ba vùng dữ liệu → ghi commit và đọc lịch sử → hiểu HEAD, nhánh và tag → merge, xung đột và cherry-pick → remote, fetch/pull/push → rebase và viết lại lịch sử → stash, hoàn tác, reflog → vận dụng một vòng thay đổi và kiểm tra bằng chứng.

**Ranh giới:** module giải thích cách Git hoạt động, không quy định thời gian sống của nhánh, Git Flow/trunk-based hay chính sách merge cấp nhóm. Pull request, merge request, quyền truy cập và bảo vệ nhánh thuộc các module nền tảng cộng tác; CI/CD, quản lý phát hành và deployment thuộc lĩnh vực khác. Tám chương bên dưới có ví dụ lệnh, điều kiện áp dụng, rủi ro, cách kiểm chứng và tài liệu Git chính thức để tự thực hành trong repository thử.
