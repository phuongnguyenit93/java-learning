# Concurrent Programming — Curriculum Boundary

**Location:** `module/platform/development/programming/paradigm/concurrent`

**Purpose:** Organize tasks that may progress independently or interleave, coordinating shared state or message exchange while preserving safety and progress.

**Prerequisites:** State, functions, asynchronous actions and basic execution flow.

**Owned topics:** Concurrency, parallelism and asynchrony; Shared state and synchronization; Visibility, atomicity and ordering; Message passing and actors; CSP and channels; Progress and liveness; Cancellation, failures and testing.

**Out of scope / integration boundary:** Language-independent models: shared memory, actors/message passing and CSP/channels. Java threads, synchronization, virtual threads and the Java Memory Model belong to Java Advance; reactive/backpressure belongs to Reactive.

**Source of truth:** `content/roadmap/vi/roadmap.yml` and `content/roadmap/en/roadmap.yml`. Future Knowledge/Menu and assessments must follow their approved scope; do not assume that content has been generated simply because the module exists.
