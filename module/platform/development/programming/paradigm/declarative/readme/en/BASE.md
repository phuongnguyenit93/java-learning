# Learning Declarative Programming

Declarative programming focuses on **describing results, relations, or constraints that must hold**, rather than directing every execution step. An evaluator or other implementation interprets that description and chooses how to process it; different strategies can satisfy the same required meaning.

Start with basic variables, conditions, simple data collections, and familiarity with ordered imperative steps. The introduction establishes intent and scope; next come specifications, constraints, and evaluation strategies. Then study logical facts, relations, and rules; explore queries and policy/configuration examples; and finish with trade-offs and connections to other styles.

This module owns the **language-neutral mental model**, not SQL optimization, Prolog syntax, inference-engine internals, or framework APIs. Functional programming overlaps with declarative style but owns purity, immutability, and function composition separately.
