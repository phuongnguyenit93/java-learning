# Lập trình logic

Mô tả quan hệ, dữ kiện và quy tắc suy luận thay vì viết thủ tục duyệt từng khả năng.

## Mục đích học

Hiểu đúng mô hình tư duy, lý do sử dụng, cơ chế vận hành, tình huống phù hợp và đánh đổi. Module dạy phạm vi **độc lập ngôn ngữ**; công cụ và framework chỉ dùng làm ví dụ đối chiếu.

## Điểm xuất phát

Biến, điều kiện và quan hệ đơn giản; biết Declarative Programming là lợi thế nhưng không bắt buộc.

## Ranh giới kiến thức

Khác với declarative tổng quan: module này đi sâu unification, resolution, backtracking, recursion và negation. Không phải bài hướng dẫn cú pháp Prolog đầy đủ, công cụ query SQL hay engine Datalog cụ thể.

## Lộ trình

1. **Quan hệ và suy luận logic:** Biết cách mô tả tính đúng đắn của quan hệ và mục tiêu, phân biệt định nghĩa quan hệ với thuật toán tìm kiếm.
2. **Dữ kiện, quy tắc và truy vấn:** Biểu diễn fact, rule và goal; hiểu cách nhiều luật phối hợp để suy ra câu trả lời.
3. **Unification và biến logic:** Hiểu matching, substitution và ràng buộc biến khi kiểm tra mục tiêu.
4. **Resolution, tìm kiếm và backtracking:** So sánh ngữ nghĩa khai báo với chiến lược thực thi; nhận diện tác động của thứ tự luật và tìm kiếm.
5. **Đệ quy quan hệ và kết thúc:** Mô hình hóa quan hệ bắc cầu; nhận diện chu kỳ, termination và chi phí tìm kiếm.
6. **Phủ định, thế giới đóng và giới hạn suy luận:** Nhận biết phủ định như thất bại không luôn đồng nghĩa phủ định logic; đánh giá các giả định và giới hạn.
7. **Mô hình tri thức và bài toán phù hợp:** Thiết kế bài toán quan hệ nhỏ, so sánh với imperative/constraint và chọn hướng phù hợp.
