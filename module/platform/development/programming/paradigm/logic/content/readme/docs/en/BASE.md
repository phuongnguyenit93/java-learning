# Logic Programming

Describe relations, facts and inference rules rather than hardcoding procedures to enumerate possibilities.

## Learning goals

Understand the mental model, motivation, execution mechanisms, suitable applications and trade-offs. This module is **language-independent**; concrete libraries and frameworks are examples, not the curriculum's owner.

## Prerequisites

Variables, conditions and simple relations; declarative programming helps but is not required.

## Scope boundaries

Unlike the declarative overview, this module studies unification, resolution, backtracking, recursion and negation. It is not a complete Prolog language course, SQL tutorial or specific Datalog engine manual.

## Learning path

1. **Relations and logical inference:** Describe relations and queries, distinguishing relational specifications from search algorithms.
2. **Facts, rules and queries:** Represent facts, rules and goals, and reason about combining rules.
3. **Unification and logic variables:** Understand matching, substitutions and variable bindings in goal evaluation.
4. **Resolution, search and backtracking:** Contrast declarative meaning with operational strategies and rule ordering.
5. **Relational recursion and termination:** Model transitive relations and identify cycles, termination and search costs.
6. **Negation and inference limits:** Distinguish negation-as-failure from classical negation and understand its assumptions.
7. **Modeling and trade-offs:** Design a small relational model and choose when logic, procedural or constraint approaches fit.

> The roadmap is the high-level source of truth. Knowledge/Menu, Quiz, Interview and experiments belong to subsequent workflow steps and are not marked complete here.
