# Logic Programming — Curriculum Boundary

**Location:** `module/platform/development/programming/paradigm/logic`

**Purpose:** Describe relations, facts and inference rules rather than hardcoding procedures to enumerate possibilities.

**Prerequisites:** Variables, conditions and simple relations; declarative programming helps but is not required.

**Owned topics:** Relations and logical inference; Facts, rules and queries; Unification and logic variables; Resolution, search and backtracking; Relational recursion and termination; Negation and inference limits; Modeling and trade-offs.

**Out of scope / integration boundary:** Unlike the declarative overview, this module studies unification, resolution, backtracking, recursion and negation. It is not a complete Prolog language course, SQL tutorial or specific Datalog engine manual.

**Source of truth:** `content/roadmap/vi/roadmap.yml` and `content/roadmap/en/roadmap.yml`. Future Knowledge/Menu and assessments must follow their approved scope; do not assume that content has been generated simply because the module exists.
