# Learning Imperative Programming

Imperative programming describes computation through actions performed in an explicit order. Some actions mutate state, but not every command changes data. This viewpoint helps explain behavior when sequencing, decisions, and repetition affect an outcome.

The starting point is basic familiarity with variables, expressions, conditions, and loops. This module introduces **commands**, **state**, and **procedures** as conceptual models rather than assuming advanced Java syntax. Start with the purpose and declarative contrast, then follow state transitions, control flow, procedural organization, and correctness/trade-offs.

This module owns the language-neutral imperative and procedural mental models. Java syntax belongs to language basics, while object responsibilities, functional purity, and intent-oriented description belong to neighboring paradigms.
