# Learning Object-Oriented Programming

Object-oriented programming (OOP) organizes software around objects with **identity, behavior, state where relevant, and responsibility**. Objects collaborate through behavioral contracts to reduce scattered rules and improve how change is managed. OOP does not mean merely placing code into many classes.

The starting point is familiarity with variables, data structures, function/procedure calls, and basic execution flow. First learn why object responsibility exists and how it differs from procedural organization; then explore object state, encapsulation, and invariants; assign responsibilities, contracts, and collaboration; continue into composition, type relationships, inheritance and polymorphism; and finally evaluate trade-offs through a complete design example.

This module owns **language-neutral object-oriented principles**. Java class/interface syntax, overriding, and dispatch belong to Java Core; DDD belongs to domain modeling, and AOP owns cross-cutting concerns.
