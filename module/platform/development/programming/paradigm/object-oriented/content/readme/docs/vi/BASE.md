# Lập trình hướng đối tượng (Object-Oriented Programming — OOP)

**Lập trình hướng đối tượng (OOP)** là cách tổ chức chương trình quanh những **đối tượng** có trạng thái, hành vi và trách nhiệm riêng. Thay vì để dữ liệu và quy tắc xử lý nằm rải rác, các đối tượng phối hợp với nhau thông qua những hành vi và hợp đồng rõ ràng, giúp chương trình dễ hiểu, dễ thay đổi và mở rộng hơn khi được thiết kế phù hợp.

Module này dẫn bạn từ khái niệm **class và object** đến **đóng gói, trừu tượng hóa, kế thừa, đa hình**, các mối quan hệ giữa đối tượng và cách áp dụng chúng để thiết kế một chương trình hoàn chỉnh. Các ví dụ sử dụng **Java** để minh họa, nhưng trọng tâm là hiểu tư duy OOP, không chỉ ghi nhớ cú pháp hay bốn tính chất. Chi tiết cơ chế ngôn ngữ Java được học sâu hơn trong các module Java Core.
