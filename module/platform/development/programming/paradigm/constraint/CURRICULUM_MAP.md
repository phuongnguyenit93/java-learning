# Constraint Programming — Curriculum Boundary

**Location:** `module/platform/development/programming/paradigm/constraint`

**Purpose:** Define variables, domains and validity constraints so a solver can search for solutions instead of hardcoding an exhaustive search strategy.

**Prerequisites:** Sets, Boolean expressions, variables and conditional rules; advanced mathematical optimization is not a prerequisite.

**Owned topics:** Constraint satisfaction foundations; Constraint modeling; Propagation and domain filtering; Search and backtracking; Optimization and soft constraints; Scheduling and allocation; Complexity and trade-offs.

**Out of scope / integration boundary:** Distinguishes constraint satisfaction from logic programming and imperative search. Owns propagation, search, optimization, hard/soft constraints; specific OR-Tools/Timefold APIs and production integrations are elsewhere.

**Source of truth:** `content/roadmap/vi/roadmap.yml` and `content/roadmap/en/roadmap.yml`. Future Knowledge/Menu and assessments must follow their approved scope; do not assume that content has been generated simply because the module exists.
