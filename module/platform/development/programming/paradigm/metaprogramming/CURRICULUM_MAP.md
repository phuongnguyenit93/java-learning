# Metaprogramming — Curriculum Boundary

**Location:** `module/platform/development/programming/paradigm/metaprogramming`

**Purpose:** Study programs that inspect, generate or transform representations of other programs (or themselves) at compile time or runtime.

**Prerequisites:** Basic source code, functions, types and compile/runtime concepts; Java reflection is not required.

**Owned topics:** Programs as data; Syntax, ASTs and representations; Staging and execution phases; Macros and hygiene; Source generation and metadata; Runtime reflection and code generation; Security, testing and trade-offs.

**Out of scope / integration boundary:** Owns conceptual code-as-data, AST, macros, code generation, staging and reflection. Java annotation processors, Lombok, bytecode instrumentation, dynamic proxies and Spring internals belong in language/framework-specific modules.

**Source of truth:** `content/roadmap/vi/roadmap.yml` and `content/roadmap/en/roadmap.yml`. Future Knowledge/Menu and assessments must follow their approved scope; do not assume that content has been generated simply because the module exists.
