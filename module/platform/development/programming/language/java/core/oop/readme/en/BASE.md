# Object-Oriented Programming

This module builds the mental model for **object-oriented design in Java**: grouping state and behavior into appropriate abstractions, controlling dependencies, and choosing inheritance, composition, and polymorphism from real domain relationships.

## Learning flow

1. the OOP mental model;
2. encapsulation;
3. inheritance;
4. polymorphism;
5. overloading and overriding;
6. composition;
7. abstraction.

## Why learn this module?

OOP is not four definitions to memorize. The ideas interact: encapsulation protects invariants, inheritance creates subtype relationships, polymorphism lets code operate through contracts, and composition often reduces coupling when an “is-a” relationship does not truly fit.

Classes and Objects provides the mechanics, while Abstract Class and Interface goes deeper into abstraction mechanisms. This module focuses on design reasoning and choosing among those mechanisms.
