# Object-Oriented Programming

Module này xây mental model cho **thiết kế hướng đối tượng trong Java**: gom state/behavior vào abstraction phù hợp, kiểm soát dependency và chọn inheritance/composition/polymorphism dựa trên quan hệ thật của domain.

## Learning flow

1. OOP mental model;
2. encapsulation;
3. inheritance;
4. polymorphism;
5. overloading và overriding;
6. composition;
7. abstraction.

## Vì sao nên học?

OOP không phải bốn định nghĩa để học thuộc. Các concept liên quan với nhau: encapsulation bảo vệ invariant, inheritance tạo subtype relationship, polymorphism cho phép code làm việc qua contract, còn composition thường giảm coupling khi “is-a” không thực sự phù hợp.

Class/Object cung cấp mechanics nền; Abstract/Interface đào sâu abstraction mechanism. Module này tập trung vào reasoning và design choice giữa các cơ chế đó.
