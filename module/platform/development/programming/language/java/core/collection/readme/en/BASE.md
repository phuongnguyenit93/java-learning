# Java Collections

This module builds a decision model for the **Java Collections Framework**: choosing abstractions and implementations from ordering, uniqueness, key/value lookup, queue semantics, mutation, equality/hash behavior, and performance characteristics.

## Learning flow

1. the collection hierarchy;
2. `List`;
3. `Set`;
4. `Map`;
5. `Queue` and `Deque`;
6. iteration;
7. ordering and sorting;
8. equality and hashing in collections;
9. mutable and immutable collections;
10. fail-fast behavior;
11. implementation choice;
12. enum-based collections.

## Mental model to retain

Do not learn Collections as a class catalog. Start from the data requirement, choose the contract first, then choose an implementation. Generics supplies type safety; Object Contract explains equality, hashing, and ordering; concurrent collections belong to the concurrency area.
