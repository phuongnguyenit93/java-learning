# Java Language Basics

This is the foundation module for the **syntax, type model, and basic execution semantics of Java source code**. Its purpose is to establish shared vocabulary before moving into the object model, Generics, Collections, OOP, and higher-level APIs.

## Learning flow

1. what the Java language is designed to express;
2. source-code structure;
3. primitive and reference types;
4. variables and scope;
5. `null`;
6. wrapper types and boxing/unboxing;
7. operators;
8. casting;
9. control flow;
10. arrays;
11. methods;
12. varargs;
13. pass-by-value;
14. packages and imports;
15. the type-system mental model;
16. a synthesis of the language foundation.

## Mental model to retain

Java always passes arguments **by value**; a reference value is not the object itself. Primitive/reference distinctions, scope, conversions, and method-call rules provide the basis for later Core modules.

This module intentionally does not go deep into object design, inheritance, collections, or concurrency; it establishes the language foundation first.
