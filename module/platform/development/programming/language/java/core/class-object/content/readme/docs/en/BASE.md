# Classes and Objects

This module builds the foundation for how Java models **types, instances, state, and object lifecycle**. It focuses on how a class defines structure and behavior, how an object represents a runtime instance, and how initialization rules establish its state.

## Learning flow

1. classes and objects;
2. constructors;
3. `this` and `super`;
4. access modifiers;
5. `static` and `final`;
6. initialization blocks;
7. initialization order;
8. object creation lifecycle;
9. nested and inner classes;
10. the `Object` class;
11. enums;
12. copy semantics;
13. aliasing and mutability;
14. immutability and defensive copies;
15. a final class/object design model.

## Mental model to retain

An object is more than “a variable containing data.” The learner should be able to trace type declaration → initialization → references/aliasing → mutation/copy → object-level contracts. Equality, hashing, and ordering belong to Object Contract; broader inheritance and polymorphism design belongs to OOP.
