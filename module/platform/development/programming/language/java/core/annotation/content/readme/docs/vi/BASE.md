# Java Core — Annotation

Annotation là cơ chế gắn **siêu dữ liệu** vào khai báo hoặc vị trí sử dụng kiểu trong mã Java bằng ký hiệu `@`. Khác với chú thích mã nguồn dành cho người đọc, annotation có cấu trúc để trình biên dịch, công cụ xử lý khi biên dịch hoặc chương trình lúc chạy khai thác. Annotation tự nó không thực hiện nghiệp vụ; ý nghĩa thực tế phụ thuộc vào thành phần đọc và xử lý thông tin đó.

Module này dành cho người đã biết cú pháp Java cơ bản, lớp, phương thức và interface, muốn hiểu cách sử dụng annotation đúng mục đích thay vì chỉ ghi nhớ tên. Bạn sẽ bắt đầu với các annotation chuẩn như `@Override`, `@Deprecated` và `@SuppressWarnings`; tự khai báo bằng `@interface`; lựa chọn phần tử, giá trị mặc định, phạm vi áp dụng (`@Target`) và thời gian lưu giữ (`@Retention`). Từ đó, bạn tìm hiểu annotation lặp, quy tắc kế thừa và cách đưa annotation vào tài liệu API.

Lộ trình gồm tám mốc, đi từ bản chất và cú pháp đến hai cách khai thác chính: **reflection lúc chạy** và **annotation processor khi biên dịch**. Phần thực hành cuối kết nối việc tự định nghĩa annotation với một bộ đọc và kiểm tra nhỏ, bao gồm cả các trường hợp đặt sai vị trí, thiếu `RUNTIME` hoặc không có annotation. Sau khi hoàn thành, bạn có thể thiết kế annotation phù hợp, chọn đúng cơ chế xử lý và giải thích vì sao một annotation được khai báo nhưng chưa chắc tạo ra hành vi mong đợi.
