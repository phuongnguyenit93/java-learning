# Java 11 và các tính năng còn hữu ích trong Java hiện đại

Java 11 bổ sung nhiều cải tiến thực tiễn cho cách viết, chạy và quan sát chương trình Java. Bên cạnh cú pháp tham số lambda linh hoạt hơn, phiên bản này giúp chạy trực tiếp tệp nguồn, xử lý chuỗi và tệp thuận tiện, gọi HTTP bằng API chuẩn và thu thập dữ liệu chẩn đoán qua Java Flight Recorder (JFR). Các kiến thức trong module được lựa chọn vì vẫn có giá trị trên JDK hiện hành, thay vì hướng dẫn những cơ chế đã lỗi thời.

Tài liệu dành cho người đã nắm Java cơ bản, lambda, collection, API bất đồng bộ và nguyên tắc kết nối mạng. Lộ trình gồm bảy mốc: sử dụng `var` nhất quán cho tham số lambda khi cần annotation; chạy chương trình nhỏ bằng `java Main.java` và tùy chọn `--source`; xử lý văn bản qua `isBlank`, `strip`, `lines`, `repeat` và đọc/ghi tệp với `Files.readString`/`writeString`; tận dụng `Optional.isEmpty`, `Predicate.not` và chuyển collection thành mảng; dùng `HttpClient` đồng bộ hoặc bất đồng bộ; ghi và phân tích sự kiện JFR; cuối cùng là tìm hiểu khả năng hỗ trợ TLS 1.3 và các thuật toán mật mã phù hợp.

Sau khi hoàn thành, bạn có thể chọn API chuỗi và tệp đúng nhu cầu, phân biệt `strip` với `trim`, xây dựng yêu cầu HTTP với timeout và xử lý phản hồi hoặc lỗi qua `send`/`sendAsync`. Bạn cũng có thể tạo bản ghi JFR bằng `jcmd` hoặc tùy chọn JVM để khảo sát CPU, bộ nhớ và đồng bộ hóa; kiểm tra khả năng tương thích TLS 1.3, nhận diện X25519 và ChaCha20-Poly1305 trong bối cảnh bảo vệ kết nối. Các ví dụ nên được xác minh trên JDK đang sử dụng và phân biệt rõ tính năng xuất hiện từ Java 11 với cải tiến của những phiên bản sau.
