# Java 18 — Những kiến thức còn hữu ích trên JDK hiện đại

Java 18 đánh dấu một số cải tiến thực tiễn của nền tảng Java, từ khả năng xử lý văn bản nhất quán giữa hệ điều hành đến công cụ phục vụ tệp, tài liệu mã và cơ chế mở rộng ở mức thư viện. Module này chỉ tập trung vào **những tính năng và nguyên tắc vẫn áp dụng trên JDK hiện hành**, không dựa vào API thử nghiệm đã thay đổi hoặc cách triển khai nội bộ đã lỗi thời. Bạn sẽ phân biệt thay đổi chính thức của Java 18 với kiến thức nền cần thiết để sử dụng chúng, tra cứu đúng hợp đồng API và kiểm chứng ví dụ trên phiên bản JDK mình đang dùng.

Bạn nên có nền tảng Java, làm việc với tệp, HTTP và các API thư viện chuẩn. Trước tiên, bạn sẽ hiểu vì sao **UTF-8 trở thành bảng mã mặc định từ JDK 18**, khi nào vẫn phải chỉ định `Charset` tường minh ở ranh giới dữ liệu và cách kiểm thử nội dung tiếng Việt mà không nhầm bảng mã tệp với console. Tiếp theo, bạn sẽ chạy **`jwebserver`** hoặc dùng **`SimpleFileServer`** để phục vụ tệp tĩnh trong môi trường học tập, phát triển hay kiểm thử; kiểm tra các yêu cầu `GET`, `HEAD` và nhận diện giới hạn của công cụ này. Phần **Javadoc `@snippet`** hướng dẫn đưa ví dụ mã vào tài liệu, chọn vùng mã từ tệp riêng và biên dịch, kiểm thử ví dụ để tránh tài liệu sai lệch so với chương trình.

Ở các mốc tiếp theo, bạn sẽ dùng **reflection công khai** để xem thành viên và gọi phương thức, đồng thời hiểu việc triển khai dựa trên **method handle** từ JDK 18 không phải lý do để phụ thuộc vào lớp nội bộ của JDK. Bạn sẽ tìm hiểu cách mở rộng phân giải tên máy và địa chỉ IP với **`InetAddressResolver`**, **`InetAddressResolverProvider`** cùng **`ServiceLoader`**, kiểm tra cả trường hợp thành công, lỗi và bộ phân giải mặc định. Module cũng nhấn mạnh việc **đóng tài nguyên tường minh** bằng `AutoCloseable`, `try-with-resources` ngay cả khi có ngoại lệ, thay vì trông chờ bộ thu gom rác. Bài thực hành cuối kết hợp tệp UTF-8, máy chủ tệp cục bộ, Javadoc snippet và bộ phân giải tùy chỉnh để bạn kiểm chứng hành vi, đầu ra và vòng đời tài nguyên trong một công cụ nhỏ.
