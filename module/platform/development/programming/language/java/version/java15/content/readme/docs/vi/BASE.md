# Java 15 — Những cải tiến còn giá trị trên JDK hiện đại

Java 15 là một cột mốc đáng chú ý của ngôn ngữ và nền tảng Java: **text block** trở thành tính năng chính thức, trong khi **record**, mẫu `instanceof` và **sealed class** còn ở giai đoạn preview và chỉ được hoàn thiện trong các phiên bản sau. Module này tập trung vào **cách sử dụng các tính năng đã ổn định và API còn được hỗ trợ trên JDK hiện hành**, không yêu cầu học lại cú pháp preview hay cơ chế đã lỗi thời. Bạn sẽ thấy các thay đổi đó giúp diễn đạt dữ liệu rõ ràng hơn, giảm mã lặp, kiểm soát hệ phân cấp kiểu và mở rộng khả năng vận hành JVM như thế nào.

Nội dung dành cho người đã biết Java hướng đối tượng, kế thừa, xử lý chuỗi và các khái niệm cơ bản về JVM. Bạn sẽ bắt đầu với **text block** để viết chuỗi nhiều dòng, kiểm soát dấu xuống dòng, thụt lề, escape và các phương thức `formatted()`, `stripIndent()`, `translateEscapes()`. Tiếp theo, bạn sẽ khai báo **record**, kiểm tra dữ liệu qua constructor, hiểu accessor cùng `equals()`, `hashCode()`, `toString()` được sinh và giới hạn **bất biến nông**. Với **pattern matching cho `instanceof`**, bạn sẽ giảm ép kiểu thủ công và xác định phạm vi biến theo luồng điều khiển. Phần **sealed class/interface** hướng dẫn dùng `permits`, `final`, `sealed`, `non-sealed` và nhận diện những giới hạn kế thừa hợp lệ. Các ví dụ đều dùng dạng cú pháp chính thức đã có trên JDK mới, đồng thời chỉ rõ nguồn gốc preview ở Java 15.

Các mốc nâng cao giới thiệu **hidden class** cho trường hợp tạo lớp lúc chạy qua `MethodHandles.Lookup.defineHiddenClass()`, phân biệt chúng với lớp thông thường về khả năng tra cứu và vòng đời. Bạn sẽ dùng **JCA** để tạo khóa Ed25519 hoặc Ed448, ký và xác minh bằng `Signature`, kiểm thử dữ liệu bị sửa và phân biệt chữ ký số với mã hóa. Với **ZGC** và **Shenandoah**, mục tiêu là kiểm tra tính khả dụng trên bản JDK đang dùng, đọc GC log và so sánh độ trễ, thông lượng, bộ nhớ thay vì mặc định một bộ thu gom luôn tốt nhất. Bài thực hành cuối kết hợp record, sealed, mẫu `instanceof`, text block và EdDSA, kèm kiểm thử lỗi và ghi nhận cấu hình JDK/GC. Kết thúc module, bạn có thể vận dụng đúng các đóng góp còn phù hợp của Java 15 trong phát triển Java hiện đại.
