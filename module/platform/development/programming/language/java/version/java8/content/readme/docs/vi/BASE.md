# Java 8 và những nền tảng vẫn được sử dụng trong Java hiện đại

Java 8 đưa vào nhiều cơ chế đã trở thành một phần quen thuộc của lập trình Java: lambda và functional interface giúp truyền hành vi như dữ liệu; Stream hỗ trợ xử lý tập hợp bằng pipeline; Optional biểu diễn kết quả có thể không tồn tại; còn `java.time` cung cấp mô hình ngày giờ rõ ràng hơn. Những nền tảng này vẫn hữu ích trên JDK hiện hành, nhưng cần hiểu đúng giới hạn của chúng và phân biệt API ra đời từ Java 8 với các API chỉ được bổ sung ở phiên bản sau.

Tài liệu dành cho người đã nắm Java cơ bản, lập trình hướng đối tượng, collection và khái niệm xử lý đồng thời. Lộ trình gồm tám mốc: nhận diện các thay đổi cốt lõi của Java 8; viết lambda, method reference và sử dụng `java.util.function` cùng phương thức mặc định trong interface; xây dựng Stream pipeline và dùng Optional phù hợp; vận dụng các API collection, Map, Comparator, chuỗi, Base64 và tệp; mô hình hóa thời gian với `java.time`; phối hợp tác vụ bằng `CompletableFuture` và các công cụ đồng thời; đọc annotation lặp, type annotation và metadata qua reflection; cuối cùng là thực hành kết hợp các thành phần trên.

Sau khi hoàn thành, bạn có thể dùng `filter`, `map`, `flatMap`, collector và `groupingBy` để xử lý dữ liệu, nhận biết đánh giá lười và tránh tác dụng phụ khi dùng Stream song song. Bạn cũng có thể chọn `Instant`, `LocalDate`, `ZonedDateTime` và `Clock` theo đúng ý nghĩa, đóng Stream tài nguyên khi làm việc với tệp, ghép tác vụ bất đồng bộ và xử lý lỗi với `CompletableFuture`, đồng thời kiểm chứng hành vi bằng ví dụ nhỏ trên JDK hiện đại thay vì phụ thuộc cách làm đã lỗi thời.
