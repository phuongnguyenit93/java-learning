# Java 9

Java 9 bổ sung nhiều công cụ, API và cơ chế tổ chức ứng dụng vẫn hữu ích khi phát triển trên các phiên bản Java hiện đại. Giá trị của phiên bản này không chỉ nằm ở cú pháp ngắn gọn hơn, mà còn ở khả năng xây dựng tập hợp không thể thay đổi cấu trúc, kiểm soát ranh giới mô-đun, xử lý dữ liệu và điều phối tác vụ bất đồng bộ. Module **Java 9** tập trung vào những kiến thức còn áp dụng được ngày nay, thay vì khuyến nghị triển khai bằng bản runtime Java 9 cũ hoặc tìm hiểu các cơ chế đã lỗi thời.

Module dành cho người đã biết Java Core, interface, generic, collection, Stream, ngoại lệ và những khái niệm lập trình đồng thời cơ bản. Bạn sẽ bắt đầu với **JShell** để thử biểu thức và API nhanh, rồi tìm hiểu phương thức `private` trong interface, cải tiến `try-with-resources` và toán tử kim cương cho lớp ẩn danh. Tiếp theo, bạn tạo collection bằng `List.of`, `Set.of`, `Map.of` hoặc `Map.ofEntries`, hiểu giới hạn về `null`, phần tử trùng và sự khác nhau giữa collection không thể thay đổi với đối tượng phần tử vẫn có thể thay đổi. Các API `takeWhile`, `dropWhile`, `Stream.ofNullable`, `Optional.stream` và `ifPresentOrElse` giúp biểu diễn luồng xử lý dữ liệu và trường hợp giá trị vắng mặt rõ ràng hơn.

Ở phần kiến trúc, bạn khám phá **Java Platform Module System (JPMS)** qua `module-info.java`, `requires`, `exports`, `opens`, sự khác biệt giữa classpath và module path, cùng công cụ `jdeps` và `jlink`. Phần nâng cao giới thiệu **VarHandle** để truy cập biến với ngữ nghĩa bộ nhớ và thao tác nguyên tử; mở rộng `CompletableFuture` bằng timeout và `delayedExecutor`, đồng thời làm quen `Flow` với cơ chế yêu cầu dữ liệu để kiểm soát tốc độ tiêu thụ. Cuối cùng, bạn dùng `ProcessHandle` để quan sát, chờ và quản lý tiến trình hệ điều hành. Sau module, bạn có thể nhận diện đúng các tính năng xuất hiện từ Java 9 vẫn phù hợp trong mã hiện đại, hiểu giới hạn của chúng và chọn cách áp dụng theo nhu cầu thực tế.
