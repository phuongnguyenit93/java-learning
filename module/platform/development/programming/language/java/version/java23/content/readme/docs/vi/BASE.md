# Java 23

Java 23 là một cột mốc trong quá trình cải tiến ngôn ngữ, công cụ và nền tảng Java, nhưng không phải mọi tính năng được giới thiệu lúc đó đều đã là API chính thức. Module **Java 23** tập trung vào những kiến thức vẫn có giá trị trong Java hiện đại: phân biệt tính năng ổn định, *preview* và *incubator* tại thời điểm Java 23, nhận diện những khả năng được hoàn thiện ở Java 24 hoặc Java 25, rồi lựa chọn JDK đang được hỗ trợ để học và áp dụng. Trọng tâm không phải duy trì một bản runtime cũ hay dựa vào cú pháp preview đã thay đổi.

Nội dung phù hợp với người đã biết Java Core, Stream, xử lý đồng thời, cấu trúc lớp và công cụ JDK cơ bản. Bạn sẽ bắt đầu từ **Javadoc Markdown** với chú thích `///`, danh sách, đoạn mã và liên kết API; sau đó tìm hiểu các hướng **cú pháp gọn** từng ở preview trong Java 23 qua dạng đã chính thức từ Java 25, như nhập mô-đun, tệp nguồn đơn giản và `main` dạng instance, cùng các quy tắc thực thi mã trước lời gọi `super(...)`. Tiếp theo, **Stream Gatherers** cho phép xây dựng thao tác trung gian với cửa sổ cố định, cửa sổ trượt hoặc tích lũy; cần phân biệt gatherer với collector và kiểm thử cả dữ liệu rỗng lẫn dừng sớm. Gatherers còn ở preview trong Java 23 và đã chính thức từ Java 24.

Ở các chủ đề nâng cao, bạn sẽ học **ScopedValue** để truyền ngữ cảnh theo phạm vi lời gọi, hiểu ràng buộc lồng nhau và khác biệt với `ThreadLocal`; **Class-File API** để đọc, tạo hoặc biến đổi class file, đối chiếu kết quả bằng `javap`. Hai API này lần lượt được chính thức hóa ở Java 25 và Java 24. Module cũng đề cập cách dùng **VarHandle** và **Foreign Function & Memory API** (`MemorySegment`, `Arena`) thay cho phụ thuộc vào API bộ nhớ nội bộ, đồng thời hiểu **ZGC theo thế hệ** là chế độ mặc định *khi chọn ZGC* từ JDK 23, chứ không phải bộ thu gom mặc định của mọi JVM. Phần thực hành kết hợp Gatherers, ScopedValue, tài liệu Markdown, cấu hình annotation processor tường minh, kiểm tra class file và đo GC bằng cấu hình JDK ghi nhận rõ ràng. Sau module, bạn có thể phân biệt trạng thái phát triển của tính năng, sử dụng dạng API đã ổn định và kiểm chứng kết quả trên JDK phù hợp.
