# Java 14

Java 14 đánh dấu sự xuất hiện của một số cải tiến vẫn hữu ích trong các phiên bản Java hiện đại: diễn đạt nhánh điều kiện rõ ràng hơn, chẩn đoán lỗi `null` chính xác hơn và quan sát ứng dụng đang chạy thông qua luồng sự kiện. Module **Java 14** chỉ tập trung vào những tính năng còn áp dụng được hiện nay; mục tiêu không phải triển khai hệ thống trên bản runtime Java 14 đã cũ, mà là hiểu cách sử dụng đúng các khả năng này trong môi trường Java được hỗ trợ.

Module dành cho người đã biết cú pháp `switch`, ngoại lệ, stack trace và kiến thức JVM cơ bản. Trước hết, bạn sẽ học **switch expression** với nhánh `case ->`, nhiều nhãn `case` và từ khóa `yield` khi một nhánh cần khối lệnh, từ đó phân biệt biểu thức trả về giá trị với câu lệnh `switch` truyền thống và kiểm tra việc xử lý đầy đủ các trường hợp. Tiếp theo, bạn tìm hiểu thông báo **NullPointerException** chi tiết do JVM tạo ra: cách kết hợp thông báo với dấu vết ngăn xếp để xác định biểu thức gây lỗi, phân biệt với ngoại lệ tự ném và sửa nguyên nhân phát sinh `null` thay vì chỉ che giấu triệu chứng.

Phần cuối giới thiệu **JFR Event Streaming** để theo dõi sự kiện trong lúc ứng dụng hoạt động. Bạn sẽ tìm hiểu cách sử dụng `RecordingStream`, lựa chọn sự kiện quan sát như hoạt động CPU hoặc thu gom rác, đăng ký xử lý qua `onEvent`, bắt đầu và đóng luồng đúng thời điểm. Việc xử lý sự kiện cũng cần đủ gọn để hạn chế ảnh hưởng đến hiệu năng chương trình đang được theo dõi. Sau module, bạn có thể viết nhánh điều kiện dễ kiểm soát hơn, xử lý lỗi `null` có căn cứ và chủ động quan sát hoạt động JVM bằng những API vẫn có giá trị trong Java ngày nay.
