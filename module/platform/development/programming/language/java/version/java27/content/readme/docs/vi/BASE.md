# Java 27 — JVM và các tính năng hiện hành

Java 27 tiếp tục phát triển nền tảng Java ở các hướng **hiệu năng JVM, lập trình đồng thời, tính toán vector và bảo mật**. Không phải mọi tính năng xuất hiện trong bản phát hành đều đã ổn định: một số vẫn mang nhãn **Preview** hoặc **Incubator**, cần kích hoạt rõ ràng và có thể thay đổi hợp đồng API. Module này giúp bạn phân biệt các mức độ hỗ trợ đó trước khi áp dụng vào dự án thực tế, thiết lập JDK 27, kiểm tra cấu hình bộ gom rác đang được dùng và đo ảnh hưởng của **compact object headers** lên bộ nhớ heap. Trọng tâm là những kiến thức còn có thể kiểm chứng trên JDK hiện hành, không học theo API đã lỗi thời hay giả định cấu hình JVM giống nhau ở mọi môi trường.

Nội dung phù hợp với người đã nắm Java, `switch`, `instanceof`, xử lý đồng thời và cách chạy ứng dụng trên JVM. Bạn sẽ thử **mẫu kiểu nguyên thủy (Preview)** trong `instanceof` và `switch`, chú ý điều kiện chuyển kiểu bảo toàn giá trị và yêu cầu `--enable-preview`. Tiếp theo, **Lazy Constants (Preview)** giới thiệu `LazyConstant.of` và `get` để trì hoãn khởi tạo, với các kiểm chứng về truy cập đồng thời và phụ thuộc vòng. Phần **Structured Concurrency (Preview)** giúp quản lý nhóm tác vụ thông qua `StructuredTaskScope`, `fork`, `join` và `Joiner`, đồng thời thực hành xử lý lỗi, hủy và đóng phạm vi. Với **Vector API (Incubator)**, bạn sẽ kích hoạt `jdk.incubator.vector`, xử lý các phần tử còn dư và so sánh hiệu năng SIMD với xử lý vô hướng trên CPU thực tế; không xem kết quả đo hay API đang thử nghiệm là cam kết ổn định lâu dài.

Các mốc cuối tập trung vào **an toàn kết nối và quan sát hệ thống**. Bạn sẽ tìm hiểu trao đổi khóa lai giữa thuật toán truyền thống và hậu lượng tử trong **TLS 1.3**, thử kết nối qua `javax.net.ssl` với máy chủ tương thích và kiểm tra thuật toán thực tế được thương lượng. **PEM API (Preview)** hỗ trợ tìm hiểu chuyển đổi khóa, chứng chỉ qua dạng PEM và vai trò của `BinaryEncodable`, song vẫn cần xác thực định dạng và bảo vệ khóa riêng. Cuối cùng, bạn sẽ thực hành **che dữ liệu nhạy cảm trong JFR**, nhận diện thông tin trong tham số lệnh, biến môi trường và thuộc tính hệ thống rồi kiểm tra bản ghi trước khi chia sẻ. Hoàn thành module, bạn có thể lựa chọn đúng phạm vi thử nghiệm, đánh giá hành vi và hiệu năng bằng bằng chứng, đồng thời tránh nhầm lẫn tính năng Preview/Incubator với API đã chính thức ổn định.
