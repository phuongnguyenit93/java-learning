# Java 6 — Những API còn giá trị trong Java hiện đại

Java 6 từng bổ sung nhiều API và cơ chế mở rộng vào thư viện chuẩn; một số trong đó vẫn hữu ích khi phát triển với các phiên bản JDK hiện hành. Module này không nhằm khôi phục môi trường Java 6 hay học lại những kỹ thuật đã lỗi thời. Thay vào đó, bạn sẽ tìm hiểu **những phần bổ sung còn được hỗ trợ**, nhận diện chúng trong thư viện Java ngày nay và biết khi nào nên sử dụng. Điểm xuất phát là phân biệt tính năng xuất hiện từ Java 6 với kiến thức nền có trước đó, đồng thời tra cứu API và kiểm chứng ví dụ trên **JDK đang được sử dụng**, thay vì giả định hành vi lịch sử luôn giữ nguyên.

Nội dung phù hợp với người đã nắm cú pháp Java, hướng đối tượng và cách làm việc cơ bản với collection, cơ sở dữ liệu hoặc tệp. Bạn sẽ thực hành **`Deque`**, **`ArrayDeque`**, **`NavigableMap`**, **`NavigableSet`** và những cấu trúc phục vụ xử lý đồng thời như `BlockingDeque` hoặc `ConcurrentSkipListMap`. Tiếp theo là các cải tiến **JDBC 4** vẫn có giá trị: cơ chế driver tự đăng ký, kiểm tra kết nối bằng `isValid()`, `unwrap()` và phân loại ngoại lệ. Với **SPI và `ServiceLoader`**, bạn sẽ học cách công bố lớp cung cấp bằng `META-INF/services`, nạp triển khai thông qua hợp đồng chung và xử lý lỗi cấu hình dịch vụ.

Các mốc sau giới thiệu **`JavaCompiler`** cùng cơ chế annotation processing qua `javax.annotation.processing` và `Filer`, giúp phân biệt sinh tệp lúc biên dịch với reflection lúc chạy. Bạn cũng sẽ đọc, ghi XML theo luồng bằng **StAX** (`XMLStreamReader`, `XMLStreamWriter`), lưu ý cấu hình an toàn cho DTD/thực thể ngoài và đóng tài nguyên đúng cách. Cuối cùng là chuẩn hóa Unicode bằng `Normalizer`, nhập liệu với `Console` và xử lý dữ liệu mật khẩu cẩn thận. Bài thực hành tích hợp kết hợp `ServiceLoader`, XML, collection và JDBC trong một ví dụ nhỏ có kiểm tra lỗi, đầu ra và giải phóng tài nguyên. Sau module, bạn có thể **chọn và vận dụng các API còn phù hợp** trên JDK hiện hành, thay vì sao chép những cách làm chỉ có ý nghĩa trong môi trường cũ.
