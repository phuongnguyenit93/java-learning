# Java 26

Java 26 mở rộng khả năng biểu đạt kiểu dữ liệu, giao tiếp mạng, điều phối tác vụ và tối ưu vận hành của nền tảng Java. Tuy nhiên, không phải mọi khả năng có mặt trong bản phát hành này đều là tính năng chính thức: một số vẫn ở trạng thái **preview** hoặc **incubator** và có thể thay đổi ở các JDK tiếp theo. Module **Java 26** giúp bạn phân biệt các mức độ ổn định, xác định điều kiện sử dụng tính năng và tập trung vào kiến thức còn hữu ích trong Java hiện đại, thay vì phụ thuộc vào một phiên bản hoặc API thử nghiệm theo cách thiếu kiểm soát.

Nội dung dành cho người đã nắm Java Core, xử lý đồng thời, HTTP, quản lý tài nguyên và các khái niệm JVM cơ bản. Bạn sẽ tìm hiểu **primitive patterns** (preview lần bốn ở Java 26), cách phối hợp với `instanceof` và `switch`, chú ý phép chuyển đổi số biểu diễn chính xác và các giá trị biên. Tiếp theo, bạn thử **HTTP/3** qua `HttpClient.Version.HTTP_3`, kiểm tra giao thức thực tế được thương lượng với máy chủ và xử lý thời gian chờ hoặc lỗi kết nối. Phần **LazyConstant** (preview lần hai) giúp diễn đạt khởi tạo trễ, kiểm tra truy cập đồng thời qua `of` và `get`, đồng thời phân biệt tham chiếu không thay đổi với tính bất biến của đối tượng.

Ở phần nâng cao, bạn sẽ khám phá **Structured Concurrency** (preview lần sáu) để quản lý các tác vụ con cùng vòng đời bằng `StructuredTaskScope`, `fork`, `join`, thời gian chờ và hủy hợp tác; **PEM API** (preview lần hai) để mã hóa, giải mã khóa hoặc chứng thư mà không nhầm việc phân tích định dạng với xác minh độ tin cậy; và **Vector API** (incubator lần mười một) cho tính toán SIMD, mặt nạ cùng phần tử còn dư trong mảng. Cuối cùng, module hướng dẫn đánh giá cải tiến **G1** và bộ đệm đối tượng **AOT** bằng số liệu khởi động, làm nóng, thông lượng thực tế; nhận diện cảnh báo khi sửa trường `final` qua reflection và rà soát thư viện trước khi nâng cấp. Sau module, bạn có thể chọn JDK cùng tùy chọn preview/incubator phù hợp, kiểm thử ranh giới hành vi và áp dụng có chọn lọc các cải tiến còn giá trị.
