# Java 7

Java 7 đã đưa vào nhiều cải tiến vẫn xuất hiện trong mã Java hiện đại, từ cú pháp ngắn gọn hơn đến quản lý tài nguyên, thao tác tệp và xử lý song song. Module **Java 7** không nhằm hướng dẫn sử dụng một bản JDK cũ trong môi trường sản xuất, mà tập trung vào những tính năng ra đời ở Java 7 **vẫn còn giá trị khi lập trình với các phiên bản Java được hỗ trợ hiện nay**. Hiểu nguồn gốc và cách sử dụng đúng những API này giúp bạn đọc mã hiện có, tránh rò rỉ tài nguyên và lựa chọn công cụ phù hợp cho công việc thực tế.

Module dành cho người đã nắm cú pháp, ngoại lệ, I/O và khái niệm luồng cơ bản của Java. Bạn sẽ bắt đầu với các cải tiến **Project Coin** như literal nhị phân, dấu gạch dưới trong số, `switch` với `String`, toán tử kim cương `<>` và điều kiện sử dụng `@SafeVarargs` an toàn. Tiếp theo là **multi-catch**, suy luận chính xác ngoại lệ khi ném lại và **try-with-resources** với `AutoCloseable`. Bạn sẽ hiểu thứ tự đóng nhiều tài nguyên, cách ngoại lệ bị giữ lại (*suppressed exception*) hoạt động, từ đó viết mã xử lý lỗi rõ ràng mà không bỏ sót bước giải phóng tài nguyên.

Phần thực hành đi sâu vào **NIO.2** với `Path` và `Files` để chuẩn hóa đường dẫn, đọc, ghi, sao chép và di chuyển tệp; dùng `walkFileTree`, `FileVisitor` và `BasicFileAttributes` để duyệt thư mục có xử lý lỗi. Bạn cũng sẽ tìm hiểu `WatchService` để phát hiện thay đổi và xử lý sự kiện `OVERFLOW` đúng cách. Cuối cùng, `ForkJoinPool`, `RecursiveTask` và `RecursiveAction` giúp bạn thực hành chia nhỏ bài toán thiên về tính toán, lựa chọn ngưỡng chia việc và đo hiệu quả so với xử lý tuần tự. Sau module, bạn có thể áp dụng những tính năng Java 7 còn phù hợp trong mã Java ngày nay, đồng thời nhận diện giới hạn của từng cơ chế thay vì sử dụng theo thói quen.
