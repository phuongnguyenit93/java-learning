# Java 17

Java 17 bổ sung những cơ chế vẫn có giá trị trong phát triển Java hiện đại, đặc biệt khi cần thiết kế hệ phân cấp kiểu dữ liệu rõ ràng, sử dụng API tiêu chuẩn thay cho tiện ích tự viết và duy trì khả năng tương thích với JDK. Module **Java 17** tập trung vào bốn nhóm kiến thức còn được áp dụng hiện nay, không đi vào những tính năng đã lỗi thời. Bạn sẽ hiểu không chỉ cách dùng API, mà còn cả các ranh giới cần tôn trọng để mã nguồn dễ kiểm soát, kiểm thử và bảo trì.

Module dành cho người đã nắm Java Core, hướng đối tượng, interface, generic, xử lý mảng byte và các khái niệm module hoặc reflection cơ bản. Phần đầu giới thiệu **sealed class** và **sealed interface** để giới hạn những kiểu con hợp lệ, sử dụng `sealed`, `permits`, `final` hoặc `non-sealed` theo mục đích mở rộng; đồng thời làm rõ các quy tắc về module và package. Tiếp đó, bạn sẽ khám phá API sinh số giả ngẫu nhiên thống nhất với `RandomGenerator` và `RandomGeneratorFactory`, chọn thuật toán và seed có chủ đích để tái lập kết quả kiểm thử. Với yêu cầu bảo mật, bạn cần phân biệt những bộ sinh số giả ngẫu nhiên thông thường với `SecureRandom` phù hợp cho dữ liệu nhạy cảm.

Lộ trình tiếp tục với **HexFormat**, sử dụng `formatHex` và `parseHex` để chuyển đổi byte và chuỗi hệ 16, tùy chỉnh chữ hoa hoặc dấu phân cách và xử lý đầu vào không hợp lệ. Cuối cùng, bạn sẽ tìm hiểu **đóng gói mạnh các thành phần nội bộ JDK**, nhận diện lỗi `InaccessibleObjectException`, dùng `jdeps` để phát hiện phụ thuộc vào API nội bộ và ưu tiên API công khai cùng thư viện tương thích thay vì dựa vào cách truy cập không được hỗ trợ. Sau module, bạn có thể áp dụng các khả năng thiết thực của Java 17 vào mã Java ngày nay và đánh giá được giới hạn an toàn, tương thích của từng lựa chọn.
