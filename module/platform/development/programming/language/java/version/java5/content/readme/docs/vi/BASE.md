# Những tính năng Java 5 vẫn hữu ích trong Java hiện đại

Java 5 đánh dấu bước phát triển quan trọng của ngôn ngữ và thư viện chuẩn với nhiều tính năng vẫn xuất hiện thường xuyên trong mã Java ngày nay. Generics giúp thiết kế API an toàn kiểu; autoboxing kết nối kiểu nguyên thủy với lớp bao; vòng lặp for-each, varargs, enum và static import giúp mã ngắn gọn, biểu đạt ý định rõ hơn. Annotation bổ sung siêu dữ liệu cho trình biên dịch và các công cụ, còn các thành phần nền tảng của thư viện đồng thời hỗ trợ tổ chức tác vụ và bảo vệ dữ liệu dùng chung.

Tài liệu dành cho người đã nắm cú pháp, phương thức, lớp, mảng và collection Java cơ bản. Trọng tâm không phải tái hiện cách lập trình của năm phát hành Java 5 mà là hiểu đúng những cơ chế còn áp dụng trong các phiên bản Java hiện nay. Lộ trình gồm tám mốc: boxing/unboxing; generics với wildcard và xóa kiểu; duyệt bằng for-each; tham số varargs; enum và EnumSet/EnumMap; annotation với Target/Retention; static import có chọn lọc; cuối cùng là Callable, ExecutorService, Future cùng các công cụ đồng thời như concurrent collections, atomic và Lock.

Sau khi hoàn thành, bạn có thể nhận biết lỗi unboxing từ giá trị null, so sánh wrapper đúng cách, viết và sử dụng API generic, chọn Iterator khi cần xóa phần tử lúc duyệt, cũng như tránh rủi ro kết hợp varargs và generics. Bạn cũng sẽ biết biểu diễn tập giá trị hữu hạn bằng enum, khai báo annotation theo phạm vi và thời điểm lưu giữ phù hợp, sử dụng static import mà không làm giảm khả năng đọc, đồng thời phối hợp tác vụ, lấy kết quả và đóng ExecutorService đúng cách. Các nội dung được đặt trong bối cảnh sử dụng Java hiện đại, không khuyến khích những thói quen đã lỗi thời.
