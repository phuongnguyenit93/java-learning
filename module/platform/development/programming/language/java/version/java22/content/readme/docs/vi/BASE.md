# Java 22

Java 22 giới thiệu những cải tiến giúp mã nguồn thể hiện ý định rõ hơn, thử nghiệm chương trình thuận tiện hơn và tương tác với bộ nhớ hoặc thư viện native qua API tiêu chuẩn. Module **Java 22** tập trung vào các khả năng ra đời ở phiên bản này **vẫn còn giá trị trong Java hiện đại**, thay vì khuyến nghị sử dụng một bản runtime cũ. Hai hướng chính là viết mã ngắn gọn, dễ đọc trong những tình huống đơn giản và quản lý chặt chẽ ranh giới bộ nhớ, tài nguyên khi làm việc ngoài heap hoặc gọi mã gốc.

Module dành cho người đã biết cú pháp Java, vòng đời tài nguyên, package, biên dịch và các khái niệm cơ bản về bộ nhớ. Trước hết, bạn sẽ tìm hiểu **biến và mẫu không đặt tên** với ký hiệu `_`: thể hiện giá trị được chủ động bỏ qua trong vòng lặp, `catch` hoặc khi phân rã record, đồng thời hiểu vì sao không thể truy cập lại giá trị thông qua tên đó. Tiếp theo, bạn sẽ thử **chạy chương trình gồm nhiều tệp nguồn** trực tiếp từ tệp khởi đầu, sắp xếp các tệp và package để trình chạy nhận ra phụ thuộc, rồi phân biệt cách thử nghiệm này với quy trình biên dịch và đóng gói một dự án hoàn chỉnh.

Phần nâng cao tập trung vào **Foreign Function & Memory API (FFM)**. Bạn sẽ sử dụng `Arena` để quản lý vòng đời của `MemorySegment`, đọc và ghi bộ nhớ ngoài heap bằng `ValueLayout`, đồng thời kiểm chứng lỗi truy cập vượt phạm vi hoặc sau khi tài nguyên đã đóng. Tiếp đó, bạn tìm hiểu `SymbolLookup`, `Linker` và `FunctionDescriptor` để xác định hàm native và mô tả đúng chữ ký khi gọi từ Java. Những thao tác này đòi hỏi kiểm soát chặt chẽ quyền truy cập native, kiểu dữ liệu và thời gian tồn tại của vùng nhớ. Sau module, bạn có thể lựa chọn khi nào nên dùng các tính năng Java 22 còn phù hợp, thử nghiệm chúng có hệ thống và nhận diện rủi ro tại ranh giới Java–native.
