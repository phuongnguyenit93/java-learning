# Java Advance — Native Interoperability

Khả năng tương tác với mã native giúp Java gọi thư viện viết bằng các ngôn ngữ như C khi cần sử dụng API hệ điều hành, tận dụng thư viện có sẵn hoặc trao đổi dữ liệu ngoài JVM. Tuy nhiên, ranh giới **Java–native** đòi hỏi hiểu hợp đồng nhị phân (ABI), kích thước và cách căn chỉnh dữ liệu, quyền sở hữu bộ nhớ và vòng đời tài nguyên. Một chữ ký hàm sai hoặc tham chiếu không hợp lệ có thể gây lỗi nghiêm trọng cho cả tiến trình. Module này giới thiệu hai hướng tiếp cận: **Java Native Interface (JNI)** và **Foreign Function & Memory API (FFM)**; FFM chính thức ổn định từ JDK 22, vì vậy cần kiểm tra phiên bản JDK trước khi thực hành.

Nội dung phù hợp với người đã nắm Java Core, cơ bản về JVM, quản lý tài nguyên và có thể đọc những khai báo hàm C đơn giản. Bạn sẽ bắt đầu bằng cách khai báo phương thức `native`, sinh header với `javac -h`, biên dịch và nạp thư viện, sau đó làm việc với tham chiếu JNI, chuỗi, mảng, ngoại lệ và quy tắc gắn luồng native vào JVM. Tiếp theo là cách FFM sử dụng `Arena`, `MemorySegment` và các layout để cấp phát và truy cập bộ nhớ ngoài heap trong phạm vi sống được kiểm soát, rồi tìm symbol và tạo lời gọi hàm native bằng `Linker` cùng `FunctionDescriptor`.

Các mốc sau tập trung vào callback từ native về Java, quản lý vòng đời `upcall stub`, xử lý mã lỗi và ngăn ngoại lệ vượt qua ranh giới không phù hợp. Cuối cùng, bạn sẽ đóng gói thư viện theo hệ điều hành và kiến trúc CPU, cấu hình quyền truy cập native phù hợp với JDK và kiểm thử lỗi sai ABI, truy cập bộ nhớ không hợp lệ hoặc rò rỉ trong tiến trình thử nghiệm riêng. Sau module, bạn có thể lựa chọn JNI hoặc FFM theo môi trường hỗ trợ, thiết kế cầu nối có hợp đồng rõ ràng và nhận diện những rủi ro đặc thù khi Java làm việc với mã native.
