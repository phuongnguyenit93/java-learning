# Java Concurrency – Fork/Join

Fork/Join là mô hình xử lý song song dựa trên tư duy **chia để trị**: phân rã một bài toán tính toán thành các tác vụ nhỏ có thể chạy độc lập, sau đó ghép kết quả. Trong Java, `ForkJoinPool` điều phối các tác vụ này bằng cơ chế đánh cắp công việc (*work stealing*) để tận dụng luồng xử lý. Mô hình đặc biệt phù hợp với công việc thiên về CPU và có thể phân chia thành các phần tương đối độc lập; hiệu quả thực tế còn phụ thuộc vào chi phí chia tác vụ, hợp nhất kết quả và mức độ tranh chấp tài nguyên.

Module dành cho người đã biết Java Core, luồng và những khái niệm đồng thời cơ bản. Bạn sẽ bắt đầu bằng cách xác định điểm dừng và bước hợp nhất của thuật toán chia để trị, rồi biểu diễn tính toán dưới dạng `RecursiveTask` hoặc `RecursiveAction`. Tiếp theo, bạn thực hành `fork`, `join`, `invoke`, `invokeAll`, tìm hiểu cách `ForkJoinPool` phân phối công việc, lựa chọn `commonPool` hoặc pool riêng và quản lý vòng đời tác vụ. Lộ trình cũng làm rõ cách nhận kết quả, xử lý ngoại lệ, hủy tác vụ và những giới hạn liên quan đến việc ngắt luồng.

Ở phần nâng cao và thực hành, bạn học cách tránh ghi tranh chấp lên dữ liệu chung, nhận diện tác vụ chặn vì I/O hoặc khóa, và tìm hiểu vai trò của `ManagedBlocker`. Sau đó, bạn điều chỉnh ngưỡng phân chia, đo lường hiệu năng theo mức song song, so sánh bản tuần tự với bản Fork/Join và triển khai thử một phép cộng hoặc tìm kiếm trên các khoảng dữ liệu. Kết thúc module, bạn có thể thiết kế một tác vụ Fork/Join có kết quả kiểm chứng được, đọc các chỉ số vận hành cơ bản và giải thích khi nào chi phí xử lý song song thực sự có lợi.
