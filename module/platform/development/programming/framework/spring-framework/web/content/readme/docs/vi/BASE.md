# Spring Framework – Web

Phát triển ứng dụng web với Spring không chỉ là khai báo một endpoint mà còn là hiểu toàn bộ hành trình của yêu cầu HTTP: từ tiếp nhận kết nối, định tuyến, chuyển đổi dữ liệu đến tạo phản hồi và xử lý lỗi. Module **Spring Framework – Web** giúp bạn xây dựng tư duy về giao tiếp web, nắm vai trò của Spring MVC và nhận biết khi nào mô hình phản ứng của Spring WebFlux phù hợp hơn. Trọng tâm là hợp đồng HTTP rõ ràng, phân tách nghiệp vụ khỏi hạ tầng web và kiểm soát hành vi của ứng dụng khi có dữ liệu hoặc yêu cầu không hợp lệ.

Module dành cho người đã biết Java, Spring IoC và các khái niệm HTTP căn bản. Bạn sẽ bắt đầu từ request/response, HTTP method và mã trạng thái, sau đó lần theo luồng Spring MVC qua `DispatcherServlet`, `HandlerMapping`, `HandlerAdapter` và controller. Tiếp theo là thiết kế endpoint với `@Controller` hoặc `@RestController`, binding và validation dữ liệu đầu vào, chuyển đổi nội dung, tạo phản hồi bằng `ResponseEntity` và chuẩn hóa lỗi. Bạn cũng sẽ tìm hiểu filter, interceptor, multipart, CORS, tài nguyên tĩnh, session và caching, đồng thời xác định ranh giới của các yêu cầu bảo mật.

Lộ trình mở rộng sang Spring WebFlux với `Mono`, `Flux`, backpressure và chuỗi I/O không chặn, rồi đến cách giao tiếp với dịch vụ khác bằng `RestClient`, `WebClient` và HTTP Service Client. Các cơ chế cập nhật liên tục như SSE và WebSocket/STOMP được đặt trong tương quan với xử lý bất đồng bộ MVC để lựa chọn theo nhu cầu. Cuối cùng, bạn sẽ kiểm thử mapping, validation, phản hồi lỗi và giao tiếp HTTP bằng `MockMvc` hoặc `WebTestClient`, đồng thời quan sát độ trễ và tài nguyên khi ứng dụng chạy thực tế.
