# Software Architecture

Software Architecture describes the high-level structure, boundaries, dependencies, communication, data flow and major trade-offs of a software system.

## Structure

- Fundamentals
- System Architecture
- Architectural Pattern
- Distributed System Design
- Domain Modeling

## Relationship with Design Pattern

- Architecture: the high-level organization of a concrete software system.
- Architectural Pattern / Architectural Style: reusable high-level approaches used to shape an architecture.
- Design Pattern: reusable design solutions at a smaller object/component collaboration level.
- Domain-Driven Design: a domain modeling and software design approach; it is not a GoF Design Pattern.
