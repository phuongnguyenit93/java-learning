# Architectural Pattern

- Layered Architecture
- Model-View-Controller (MVC)
- Hexagonal Architecture / Ports and Adapters
- Clean Architecture
- Onion Architecture
- Client-Server Architecture
- Event-Driven Architecture
- Microkernel / Plugin Architecture
- Pipes and Filters
- Service-Oriented Architecture (SOA)
- Modular Monolith

- Architectural Pattern is a reusable high-level solution for organizing software structure and interactions.
- A concrete system architecture may combine more than one architectural pattern or style.
- Microservice architecture is owned by `module/microservice` to avoid duplicate curriculum ownership.
